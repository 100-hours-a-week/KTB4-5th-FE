## 💡 어떤 문제를 푸나요?

냉장고에 뭐가 있는지, 언제까지 먹어야 하는지 일일이 기억하기 어려워 **식재료를 버리게 되는 문제**를 해결합니다.
재료를 한 번 등록해 두면 **유통기한 임박순으로 정리**하고, **임박·만료 재료를 매일 알림**으로 챙겨줍니다.

<br>

## ✨ v2 주요 기능

| 기능 | 설명 |
| --- | --- |
| **간편·카카오 로그인** | 아이디·비밀번호 로그인과 카카오 OAuth 기반 소셜 로그인 지원 |
| **매일 아침 알림** | 유통기한 3일 이내(D-3)·당일 만료 재료를 매일 오전 8시 푸시 알림으로 전달 |
| **홈 대시보드** | 보관 중인 재료 수(최대 100종)와 오늘 챙겨야 할 재료를 한눈에 |
| **냉장고 목록·검색** | 보관 방법·카테고리별 필터, 재료 이름 검색, 유통기한·등록일·이름순 정렬 |
| **재료 직접 등록** | 여러 재료를 한 번에 직접 입력 (이름·카테고리·보관 방법·수량·무게·유통기한) |
| **영수증 인식 등록** | 영수증 사진에서 재료를 자동 인식(OCR)하고, 인식 결과를 확인·수정한 뒤 등록 |
| **공유 냉장고** | 가족·룸메이트 등 여러 사용자가 하나의 냉장고에 있는 재료를 함께 관리 |
| **특수 냉장고 입장** | 오픈채팅방에 참여하듯 카카오테크 부트캠프 구성원을 위한 공용 냉장고에 입장 |
| **재료 상세·수정·삭제** | D-day 확인, 보관 방법 변경, 다 먹은 재료 삭제 |
| **알림함** | 받은 알림 조회 및 읽음 처리 |
| **마이페이지** | 프로필 편집, 푸시 알림 켜기/끄기, 로그아웃 |

> 📱 앱 설치 없이 홈 화면에 추가해 앱처럼 사용할 수 있어요 (PWA)

## 🗺️ 업데이트 계획

| 버전 | 일정 | 핵심 목표 |
| --- | --- | --- |
| **v1** ✅ | ~ 10/2 출시 | 재료 직접 등록 + 유통기한 알림 |
| **v2** ✅ | 10/5 ~ 10/23 | 영수증 촬영 등록, 냉장고 공유 |

### v3 — 남은 재료로 뭘 해 먹을지까지

- **보유 재료 기반 AI 요리 추천**
  - 유통기한 임박 재료 우선 추천
  - 요리 상세 조회
  - 레시피를 고르면 들어가는 재료를 냉장고에서 자동 차감
  - AI 오류·결과 없음 상황 안내
- **실물 사진으로 재료 등록**
- **알림 → 요리 추천 바로가기**
